# Аудит StudyHour — 6 ноября 2026

Проверен исходный код ветки main после отмены автоматического администратора. Область: зависимости, HTTP API, аккаунты, роли, SQLite, тарифы, даты, Excel, запуск, интерфейс и CSS. Это аудит текущего сервиса предзаказов, а не сертификация безопасности или обещание отсутствия любых ошибок.

## Добавлено

- Администратор может искать заявки по имени, email, сервису и номеру, фильтровать статус и отменять заявку с подтверждением. Роль проверяется сервером.
- Кнопка обновления своих заявок и подтверждение отмены.
- Ссылка на поддержку из окна входа; переключение режима входа блокируется во время отправки.
- Доступные названия диалогов и поиска, заметный клавиатурный фокус, reduced-motion, перенос длинного email.

## Проверки

- Чистый npm ci --include=dev выполнен в Linux. TypeScript, интеграционные тесты и production-сборка успешны.
- Тарифы, ограничение 7 дней, шаг 30 минут, граница года и UTC+5 проверяются тестами.
- Проверены права пользователя/администратора, изоляция заявок, запрет чужого Origin, неверные JSON/content-type, смена пароля, завершение сессий, rate limit и сохранение SQLite.
- Расширены проверки повторного бронирования, повторной отмены и отмены администратором.
- В облачном браузере проверены каталог, тариф Gemini 2 часа / 750 ₸ и крайний доступный день колёсика. Мобильные CSS проверены по коду; реальные iOS/Android и macOS ARM в этой среде не запускались.
- Админские операции проверены через API. Полный браузерный сценарий регистрации/входа/админки и нагрузочное тестирование в эту проверку не входят.

## Остаётся перед коммерческим запуском

1. Оплата, выдача реального ИИ-доступа и Turnitin не подключены. Сайт явно обозначен как предзаказ; эти функции нельзя считать реализованными.
2. Нужен email-провайдер для подтверждения адреса и самостоятельного восстановления пароля. Сейчас помощь — через Telegram.
3. Нет учёта вместимости провайдеров и запрета пересекающихся сессий разных пользователей: для предзаказа это допустимо, для оплаченной аренды потребуются ресурсы и атомарное резервирование.
4. Требуются реальный HTTPS-домен, постоянный диск, резервные копии с проверкой восстановления и мониторинг. SQLite рассчитана на один экземпляр приложения с общим диском.
5. Ограничение запросов использует адрес соединения. За reverse proxy лимит может быть общим для клиентов; доверие к forwarded-заголовкам нужно настраивать только под конкретный доверенный proxy.
6. Интерфейс показывает последние 500 личных / 1000 административных заявок; Excel выгружает все. Для большого объёма нужны серверная пагинация и потоковый экспорт.

## Обновление на Mac из ZIP

Сохраните `.data` и `.env`, обновите исходники, затем выполните:

```bash
npm ci --include=dev
npm run dev
```

Не переносите старый node_modules. Для production: npm run build, затем npm start. Реальные аккаунты и базы в репозиторий не включены.
